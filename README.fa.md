# Cloudflare Edge Scanner

این ابزار یه برنامهٔ خط فرمانیه که می‌تونه هم با رابط کاربری متنی (Textual TUI) اجرا بشه، هم بدون رابط کاربری. کارش اینه که پیکربندی‌های پروکسی VLESS/VMess/Trojan رو بررسی کنه، آدرس‌های لبهٔ Cloudflare رو پیدا کنه و سرعت و کیفیت اتصال رو بسنجه.

## چی کار می‌کنه

- پیکربندی‌های URI پروکسی رو از فایل، لینک اشتراک یا قالب می‌خونه
- نام دامنه‌ها رو تبدیل به IP‌ های Cloudflare می‌کنه
- تاخیر، زمان TLS و سرعت دانلود رو روی سرورهای Cloudflare تست می‌کنه
- بهترین IP‌ها رو رتبه‌بندی می‌کنه و خروجی می‌فرسته به CSV و JSON
- می‌تونی با TUI کار کنی یا بدون صفحه و headless اجراش کنی
- یه قابلیت داره برای پیدا کردن IP‌های "تمیز" Cloudflare و هم ابزارهایی برای ساخت و تست کانفیگ Xray داره

## سریع شروع کن

1. Python 3.11 یا بالاتر نصب کن و بسته‌های لازم رو بریز.
2. از فولدر اصلی پروژه این دستور رو اجرا کن:

```bash
python3 main.py -i config.txt
```

3. اگه نمی‌خوای رابط TUI بیاد بالا:

```bash
python3 main.py -i config.txt --no-tui
```

## ساختار پروژه

```
.
├── README.md
├── README.fa.md            # این راهنمای فارسیه
├── config.txt              # نمونه فایل ورودی
├── docs/                   # مستندات پروژه
│   ├── architecture.md
│   └── usage.md
├── main.py                 # نقطهٔ شروع برنامه
├── results/                # نتایج اسکن و لاگ‌ها اینجا ذخیره می‌شن
├── src/                    # کدهای اصلی برنامه
│   ├── app.py              # پیاده‌سازی رابط Textual
│   ├── config_parse.py     # خواندن و تجزیهٔ URIها
│   ├── constants.py        # مقدارهای پیش‌فرض و دامنه‌ها
│   ├── core.py             # هماهنگی اسکن و خروجی گرفتن
│   ├── deploy_utils.py     # ابزارهای استقرار Xray روی لینوکس
│   ├── models.py           # مدل‌ها و حساب‌کردن امتیاز
│   ├── rate_limiter.py     # کنترل سرعت درخواست‌های Cloudflare
│   ├── speed_test.py       # تست‌های سرعت و تأخیر
│   ├── tui.py              # صفحه‌ها و کارهای رابط متنی
│   ├── utils.py            # ابزارهای کمکی کنسول
│   └── xray_utils.py       # ساخت کانفیگ Xray و URI
```

## مستندات

- `docs/architecture.md` — چطوری ماژول‌ها با هم کار می‌کنن
- `docs/usage.md` — نحوهٔ استفاده، فرمت فایل ورودی و مثال‌ها

## چند نکته مهم

- نتیجه‌ها و گزارش‌های دیباگ توی `results/` ذخیره می‌شن
- فرمت‌های پشتیبانی‌شده: `.txt`، `.json`، `.conf`، `.lst`
- `config.txt` یه نمونه فایل هست که URIهای VLESS/Trojan توش هستن
